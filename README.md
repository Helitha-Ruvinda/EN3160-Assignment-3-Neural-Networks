# EN3160 Assignment 3 — Neural Networks

Implementation and evaluation of neural networks for image classification as part of the EN3160 Computer Vision course at the University of Moratuwa.

## Assignment Tasks

- **Question 1 — Fully Connected Neural Network:** Implement a neural network with one hidden layer using manual forward propagation and backpropagation, trained with cross-entropy loss on CIFAR-10.
- **Question 2 — Convolutional Neural Networks:** Implement and evaluate LeNet-5 on MNIST and a modern CNN with three convolutional layers, batch normalization, and dropout.
- **Question 3 — Transfer Learning:** Use a pretrained ResNet-18 for image classification on the Hymenoptera dataset using fine-tuning and a frozen feature extractor.

The Python scripts will contain the implementations and experiments for each question. The Jupyter notebook will organize the selected code, explanations, experimental results, plots, confusion matrices, and comparisons for the final report.

## Evaluation and Results

The experiments will evaluate training and test accuracy, training and test loss, and test-set confusion matrices where required. The results will be compared and discussed in the final report.
